## Akış (mevcut)
- Start → `start-button` → `ToolkitGameUI.PrepareLevel` → `GameManager.PrepareLevel` → Ready (level Start'ta zaten yüklü; menü dünyası → oyun kamerası).
- Win → Continue → collection tween biter → `FinishResultTransition(false)` → `GameManager.LoadNext`.
- Fail → Retry/X → RetryFade biter → `FinishResultTransition(true)` → `GameManager.Retry`.
- Pause → Restart / Main Menu onayı → `GameManager.Restart` / `QuitToMenu`.
- Ready'deki ekran dokunuşu `InputHandler.ScreenTapped` → `GameManager.OnScreenTapped` (UI Toolkit bunu engellemez).

## Plan / kararlar
- Yeni partial: `Scripts/UI/ToolkitGameUI.Transition.cs`. Overlay kodda bir kez oluşturulur, `rootVisualElement`'in son çocuğu (uxml/uss'e dokunmadan, T2 ile çakışmasın).
- Fade-out 0.3 sn InOutSine → kararmışken aksiyon → en az 2 kare + 0.08 sn bekle (level kurulum takılması fade-in'i yemesin) → fade-in 0.3 sn. DOTween, SetUpdate(true), tekrar kullanılan tween.
- Kilit: overlay picking=Position (UI tıklamaları) + `GameManager.InputLocked` (ekran dokunuşu Ready'yi başlatmasın). Aksiyon varken ikinci istek yok sayılır.
- Can yoksa Play fade'siz (mevcut NoLives uyarısı).
- Pause Restart/Main Menu: oyun pause'da kalır, fade sonrası çağrılır.
