# ZLE — Interactive level editor

- Rebuilt `LevelEditor.unity`: SafeArea, Fredoka controls, 154 px top bar, bus chips, scrollable passenger palette, board input/drag ghost, tunnel and passenger popups, bottom status and solver labels. Every serialized editor reference is assigned. Both popup roots start inactive; their controllers stay active to initialize listeners.

LevelEditor's background uses Screen Space Camera at distance 99 so it stays behind the 3D preview. No GameManager, GameplayController or InputHandler is present. Game.unity is unchanged; Game is first and LevelEditor second in Build Settings.
- Added the procedural 128 px passenger silhouette and cell-sized translucent dashed void-marker prefab/material/texture. Buttons use the ZFIX sliced-height recipe. Labels use Truncate because Fredoka has no ellipsis glyph.
- Preserved Claude's scripts. Only additional source fix: `LevelSolver.cs:143`, added the missing constructor argument `3` in `ReplaySettled` (CS7036). Claude's existing one-line ZM2b API fix is included. Save's bool-returning method is invoked by a persistent `SendMessage("Save")` listener; the seconds end-edit event invokes ApplyTime with a void listener.
- The supplied scripts enumerate seven colours, including White, so the bus/tunnel add rows and palette support all seven rather than silently dropping one.
